How AuraMed AI Operates

A transparent 4-stage pipeline that converts complex symptom patterns into validated clinical recommendations.

Step 1: Patient Data & Symptom Ingestion

The patient or clinical user enters chief complaints, onset duration, vital signs, and existing prescriptions. AuraMed normalizes raw text using standardized medical terminology (SNOMED-CT / ICD-11).

  • Natural Language Symptom Extractor
  • Automatic Vital Signs Flagging
  • Existing Profile & Medical History Sync
Ingestion Payload
{
  "patient_id": "PT-94820",
  "chief_complaint": "Severe dyspnea and retrosternal pain",
  "vitals": {
    "bp": "145/95",
    "hr": 110,
    "spo2": 93
  }
}

Step 2: Adaptive Questioning & Differential Synthesis

Rather than relying on static questionnaires, AuraMed's probabilistic engine identifies key missing clinical markers and poses targeted, high-yield follow-up questions to narrow down differentials.

  • Dynamic Bayesian Entropy Reduction
  • Targeted Symptom Clarification
  • Differential Likelihood Ranking
Adaptive Clarification
{
  "status": "adaptive_clarification_required",
  "suggested_question": "Does the pain worsen with deep inspiration?",
  "differentials": ["ACS (82%)", "Pleurisy (12%)"]
}

Step 3: Safety Guardrails & Drug Interplay Check

Before any recommendation is finalized, the safety layer verifies proposed treatments against the patient's existing drug regimen, kidney/liver organ function metrics, and known allergies.

  • Multi-Drug Contraindication Matrix
  • Renal & Hepatic Dose Scaling
  • Black Box Warning Alerts
Safety Verification
{
  "safety_status": "APPROVED_WITH_WARNING",
  "contraindications": [],
  "dosage_adjustment": "Reduce Metformin dose by 50% (eGFR < 45)"
}

Step 4: Transparent Explainable Recommendation

The clinician receives a comprehensive decision support card complete with triage level, differential rank, recommended diagnostic tests, safety notes, and audit-ready literature citations.

  • Full Clinical Rationale Breakdown
  • Direct Medical Citation Links
  • Audit Log Session Snapshot
